# 失落星核 RC3 實體操作驗收

版本 0.6.1-g08-rc3／Windows x86_64。請保留 exe 與 pck 在一起。

請啟動 start_rc3.cmd，或在 PowerShell 執行 ./play_rc3.ps1。此入口使用同目錄 user_test 內的獨立存檔；重新啟動相同入口可以續玩。不要把 user_test 複製至正式存檔位置。

WASD／方向鍵移動，E 互動；對話用 E／空白鍵／Enter 或畫面按鈕。M 開旅途手冊，Esc 關閉，F5 保存，F9 讀取；Xbox 沿用既有左搖桿／A／B／Menu 配置。
