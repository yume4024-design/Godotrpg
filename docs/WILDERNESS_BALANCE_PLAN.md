# 擴充怪物低等級驗證

日期：2026-10-15。限定四種新增怪物，不調整主線、經濟、模型或存檔格式。

## 方法與門檻

Session 為單場回合戰鬥；Threat 為敵人的既有技能及選擇目標 AI；Defense/agency 為普攻、星火與治療；Resources 為 HP/MP。無反應時間、物理命中、隨機傷害或新增獎勵，因此採實際 Godot BattleManager 確定性情境測試，不建立平行公式或 Monte Carlo 模擬器，也不將重複同一情境當成人類勝率。

讀取正式角色、技能、怪物 Resource 與 expanded_battles.json。每場重新建立隊伍，角色等級 1、無裝備、無藥品，礦坑亦使用這組保守條件。

四種怪物 × 三種策略：滿血普攻、60% HP 普攻、60% HP 戰術（雷恩使用星火，莉雅在有人低於60% HP時治療；MP不足改普攻）。每場門檻：正常結束、兩人生還、2～6回合、單次結算與金幣不變。每場有1800幀上限，總共必須產生12個結果。

## 邊界與下一步

這是固定策略、單場的工程驗證，不是人類勝率、低MP連戰、故意錯誤操作或 Android 真機驗收。主線數值與正式 v0.6.1 不變。下一步可驗證新外圍座標的跨程序存讀，以及進一步實際試玩難度；環境密度與地形細化另列工作，不在本輪擴展。
