# RC4 Windows 驗收操作

可玩包：`builds/g08/rc4-fixed-0bb2188-v2/candidate/start_rc4.cmd`。

本包遊戲來源為 `0bb2188df3fb25e61e58b1944f47e4b855f464f4`，版本 `0.6.1-g08-rc4`。EXE／PCK 須放在一起；啟動器將存檔與日誌隔離到同目錄 `user_test`，保留原正式 v0.6.1、RC3 及系統存檔。此處是候選測試包，不是發佈版。

先開啟載入畫面，進入村莊後依序檢查：

1. WASD／方向鍵或 Xbox 左搖桿行走；按住 Shift／Xbox LS 跑步，放開回走路。觀察雷恩／莉雅與建物比例、腳部間距及停止姿勢。
2. 序章旅館醒來、公會接任務、莉雅入隊、低語森林教學戰、礦坑 Boss、回村交付；檢查戰鬥與探索的模型及動畫切換。
3. 與道具商購買、旅館住宿，查看金幣／道具及全隊 HP／MP。
4. 保存後正常關閉，重新開啟相同啟動器讀取；確認任務完成、隊伍／背包／單次星印和位置保留。
5. 分別用鍵鼠與 Xbox 回報結果；失敗時記錄位置、操作與 `user_test` 下最新日誌。原 RC3 的通過不視為本包通過。

本輪男性村民保留，女性暫留候選；新雷恩可玩候選與新莉雅靜態候選沒有冒充已換入本包。Android／iOS 暫停。
