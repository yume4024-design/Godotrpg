# 《失落星核》Windows 候選測試版

版本：**0.6.1-g08-rc2**，Windows x86_64。請解壓縮完整資料夾，保持 `ProjectCrystal.exe` 與 `ProjectCrystal.pck` 在一起，再開啟 exe。

## 操作與路線

- WASD／方向鍵移動，E 互動；對話可用 E、空白鍵、Enter 或畫面按鈕。
- M 開啟旅途手冊，Esc 關閉；F5 保存，F9 讀取。
- 戰鬥可用滑鼠或方向鍵／Tab 與 Enter；沿用 Xbox 手把配置。
- 旅館開場 → 公會接委託、莉雅加入 → 裝備武器 → 西側低語森林及教學戰 → 礦坑星晶與守衛 → 回公會交付。

本包使用既有新版灰石村存檔槽位，保存會更新該槽位；舊正式版的存檔槽位保留。匯入舊檔沿用既有驗證及安全出生點遷移，原始舊檔保留。第一章目前僅解鎖並顯示預告。

## 尚待改善

本包仍保留測試工具列。礦坑十一根橫梁會在遮住角色時退讓；新版入口支援最高 18 公分低台階（已測三階各 12 公分）。其他物件遮擋、角色近景瑕疵與完整地形驗收仍待改善；載入與戰鬥可能有短暫尖峰。候選版尚未完成發佈驗收，Android／iOS 暫停。

本輪以獨立 QA release 執行自動化序章、交易、舊檔遷移及重啟測試；共用遊戲資源逐檔比對一致。這不是玩家人工完整通關或所有 Windows 硬體相容保證。
