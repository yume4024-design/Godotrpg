## 缺陷與修整

原幾何切面發現腿部同一高度有多圈重疊表面。只切衣擺會留下跟著不同腿骨變形的白邊與薄片，因此本輪改成實際重拓樸：替換腰帶以下至靴口的污染褲面、建立共享襠縫的雙腿體積、兩個前後開衩的側包覆衣擺，以及一條連續腿帶。臉、頭髮、上衣、手、靴子與可見皮包沿用原表面。

最終面清單明確替換 4142 原面，8666 個未選原面保留；236 個邊界原面另外裁剪。保留部分共 9023 三角面、8902 個來源 face ID，不把裁剪片誤寫為所有原面位元相同。964 個指定皮包 face ID 全數保留。腰包改跟腰帶、腿包改跟同一腿，避免一塊附件兩端分別綁 Torso 與腿骨。新衣厚 3mm，腿帶厚 2.5mm。

新衣使用獨立 1024×512 連續 UV atlas，轉取原色並清理舊折疊白邊及重複腰帶印色；原 4096² 身體 albedo 原封保留。褲型以原網格切面量測校準，沒有直接降低腿部動作幅度或使用全域 Decimate。

### 角法線原因

本例四個狹長三角面在 Blender `custom_normal / INT16_2D` 編碼時，第二分量被編成0。加 sharp 邊及反覆改輸入向量仍失敗，紀錄保留。局部依實際解碼向量求整數編碼，不修改目標法線或原本 `.002` 門檻；獨立重新開檔後，保留角法線最大差 **.001959464**、零個超標角。

保留表面的最大位置差 **1.22905e-7m**、UV差 **1.68587e-7**。19骨 rest 及七動作127影格骨矩陣最大差均 **0**；原packed albedo SHA仍存在且相同。最終縫合不再更動原表面的幾何／UV／法線、權重或動作。這些保留檢查不適用於刻意重建的新褲面／衣面。

```powershell
./tools/godot.ps1 -Mode VisualRenAuthored
./tools/godot.ps1 -Mode TestPixalCharacters
```

完整重建／檢查使用新輸出資料夾，命令及SHA見 [單件證據](../source_assets/character_rebuild_20261020/ren/authored_garment_acceptance/README.md)。v3 Native作為固定縫合輸入保留；最後Native與GLB為必要工作原件，每件約12MB，失敗大模型／原尺寸PNG與本機存檔不入Git。
