### 世界的秘密

星核其實是世界自然魔力的調節中樞，其中保存著名為「艾絲特」的古代意識。

星晶是它向地表釋放的能量結晶，本應隨時間自然回到地脈。但人類過度開採、將能量永久封存，造成地脈失衡。

魔物暴走、森林枯萎及地震，都是世界試圖恢復平衡時產生的現象。

遠古文明曾經遭遇相同危機，他們留下了五枚「星印」，能啟動星核的修復機制。

這五枚星印就是主線冒險的核心收集目標。

### 必須遵守的執行規則

1. 事件只執行一次： 完成旗標持久化，防止玩家反覆領取獎勵。
2. 事件支持條件： 只有達成所有 `conditions` 才能觸發。
3. 戰鬥要等待結果： E004、E007 必須確認戰鬥勝利才設定完成旗標。
4. 對話與動作分離： 對話關閉後再執行需要等待的場景動作。
5. 任務可恢復： 重新讀取存檔時可還原任務狀態。
6. 每個獎勵只發一次： E005 的恢復藥暫作探索獎勵，日後如改成寶箱，必須遷移獎勵來源，不能兩者同時給予。
7. 旗標不可任意改名： 修改已發布的事件 ID 或 Flag 時，需考慮舊存檔相容性。
8. 資料先驗證再執行： 未知動作、重複事件 ID、找不到的道具或戰鬥 ID 都要報告錯誤。

# Codex 任務：實作《失落星核》序章劇情系統

你是 Godot 4 資深遊戲工程師，負責將 Project Crystal 的劇情企劃轉換成可遊玩的 3D RPG。

## 開發目標

按照《失落星核》故事設定，實作序章《灰石村的異變》，讓玩家從灰石村出發，完成公會委託、招募莉雅、探索森林與礦坑、挑戰腐化守衛，最後回村回報任務。

8. 執行測試並修正發現的錯誤。

- 戰鬥勝利後才能執行相關完成事件。
- 防止重複發放道具、金幣及經驗值。
- 存檔必須保留事件與任務進度。
- 若既有功能尚不存在，使用明確標示的可測試佔位實作。
