## 過程中修復

- 場景生成函式的節點型別參數與互動 kind 同名，造成首次建置失敗；重新命名後匯入成功。
- JSON 將數字讀回 float，與記憶體中的 int 獎勵字典直接比較不同；統一成 JSON 基本型別後再做完整驗證，保留數值必須為整數的限制。
- 測試用固定幀數等待转場，在高幀率圖形模式過早結束；改用有時間上限的輪詢，不跳過轉場條件。
- 小視窗測試滑鼠座標未包含視窗縮放；改用 Viewport 的最終變換後操作實際按鈕。
- 讀取位置隔離驗證初版沒有明確建立 World3D，造成空引用；改用獨立 World3D，再驗證地板和膠囊碰撞。
- P2 舊資料數量斷言只接受八事件；明確驗證原八事件和追加 E009 全部存在，保留其餘回歸行為。

## 限制及下一步
