## 測試覆蓋與方法

- E001 開場輸入鎖、事件完成時機、不能重播；E002 前置條件、接受 Q001／更新目標、不能重複接取。
- E 鍵啟動互動、空白鍵先顯示全文不跳句；對話中 WASD／R 不生效，結束後移動恢復。
- 使用 InputEventKey 經專案 Input Map 驅動真實玩家物理移動，從村莊出生點走近公會長；未重寫測試專用角色邏輯。
- 遠距不可互動；於寶箱前放入暫時物理牆，驗證射線阻擋；測試結束移除該測試障礙。
- 單次寶箱／未知道具／負數數量；領取、切圖、返村、再互動後乾糧仍只有一份，potions 為零。
- 切圖立即上鎖，重複切換拒絕；出生點離出口互動範圍外；只有一個地圖，旗標／任務／背包沒有重建。
- 森林空地鏡頭大小為 14，保留固定角度；返村恢復 17。
- E003／E004 未啟用，沒有寫入入隊完成或勝利旗標；莉雅只播放環境對話。
- JSON 拒絕重複事件、未知動作、缺欄位、未知說話者／旗標、非整數數量、錯誤戰鬥門檻／任務 ID、錯誤巢狀型別／初始事件型別，以及缺少開場／公會入口、錯誤初始事件／場景觸發綁定；拒絕後仍可重新驗證正確資料。
- 獨立 runner 以空旗標驗證 E002 不會接受任務；把後續階段動作加入 E001 時，整個事件在對話與旗標修改前拒絕。

圖形整合測試會操作同一個 Main 與 Input Map，產生真實遊戲畫面；部分獨立邊界案例使用 reset_to 安排位置，因此不宣稱整段流程完全由人在鍵盤上連續走完。另以 Computer Use 操作正常 Run 視窗，實際空白鍵由旁白進雷恩、E 結束開場並顯示前往公會目標、滑鼠按鈕進下一句。持續移動和碰撞由 P1／P2 引擎輸入測試驗證。

## 本輪發現並修復

1. 手寫場景中的小數缺少前導 0 導致 Godot 解析失敗，已修正並重新 Check。
2. 脫離短命工具 shell 的 console 包裝器留下空白視窗；Run／Editor 改啟动同版本 GUI 執行檔，實際關閉／重啟驗證成功。
3. 圖形模式中物理幀可能先於緩衝輸入處理，測試的按鍵 helper 增加 process_frame 等待；不以改變遊戲成功條件避開失敗。
4. Windows UI 自動化送入的邏輯 E 為 69、physical_keycode 卻為 4194313；對話 Input Map 增加邏輯按鍵相容並保留實體綁定，加入三項檢查，原生視窗重驗通過。這是注入事件相容性，不推論所有實體鍵盤都有問題。
5. 3D 名稱太小、路面交接處重疊產生雜點；調整標籤尺寸、道路拆為不重疊區塊，重新渲染查看。
6. 加強開場綁定驗證時，錯誤資料中的 Array 與 String 直接比較會產生 GDScript 錯誤；改為先檢查型別再比較，58／66 項最終測試及工具錯誤掃描皆通過。
