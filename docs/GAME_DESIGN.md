# 遊戲設計基準

## 目標

遊戲名稱《失落星核》，專案代號 Project Crystal，Windows 單機 3D 劇情 RPG。世界為艾斯特拉（Aestra），故事以冒險、發現、友情與成長為核心。參考經典 FF7 的探索、隊伍與指令戰鬥結構，使用原創世界、角色、故事及資產。先用幾何體完成玩法；正式美術採低多邊形、PS1 復古方向。

故事基準為 [Story Bible v1.0](STORY_BIBLE.md)，範圍調整及資料約定見 [整合規格](STORY_IMPLEMENTATION.md)。完整遊戲目標為序章＋四章＋終章、六大區域、雷恩/莉雅/艾琳三名核心角色、約 12～16 小時、三種結局；這些是序章完成後逐章交付的範圍。

## 可玩循環與時間配置

村莊教學/接任務/莉雅入隊（4～6 分鐘）→ 低語森林探索及教學戰（5～7 分鐘）→ 礦坑探索與星晶事件（5～8 分鐘）→ Boss、回村及結算（6～9 分鐘）。分段是暫定預算；整體仍須實測調整至 20～30 分鐘，不以加總預算代替驗收。

最終主線串起：旅館新遊戲 → 公會長瑪爾克交付 Q001 → 與莉雅交談入隊 → B001 勝利 → 礦坑取得恢復藥 x2 → 星晶回憶與第一枚星印 → B002 勝利 → 回村交付 Q001、獲得 150 金幣/200 EXP 並解鎖第一章。E005 暫以探索事件發藥，不能另放一份同來源寶箱獎勵。

## 本輪邊界

Phase 1／2 已完成移動、碰撞、灰石村／低語森林探索、對話、E001/E002、Q001 接取與一次性補給。戰鬥、隊伍養成及存檔仍未開始。可使用並修改有合適授權的素材商店資產，記錄於 ASSET_CREDITS；現階段採自製幾何體。低語森林為序章地圖，翠影森林為第一章地區，兩者不可混用。

ATB、召喚、技能樹、世界地圖、交通工具、大型分支劇情與多人玩法不納入第一個試玩版。技能及回合排程保留分離邊界，之後才能替換排程，不先實作 ATB。
