# 《失落星核》灰石村 Windows 預覽

功能分支預覽：0.6.1-g06-preview。解壓縮整個資料夾，再開啟 ProjectCrystal.exe；exe 與 pck 必須放在一起。

本包直接進入新版灰石村，包含雷恩、莉雅的新模型與莉雅七段動作、法杖及技能／道具演出。探索仍由雷恩代表隊伍；莉雅在公會入隊後於戰鬥登場。

## 操作

- WASD／方向鍵移動，E 互動；對話可用 E、空白鍵、Enter 或畫面按鈕。
- M 開啟旅途手冊，Esc 關閉；F5 保存，F9 讀取。
- 戰鬥使用滑鼠，或方向鍵／Tab 與 Enter；Xbox 手把沿用遊戲既有配置。

## 序章路線

旅館開場 → 公會接委託、莉雅加入 → 裝備武器 → 西側進低語森林、補給與教學戰 → 礦坑調查與星晶 → 腐化守衛 → 回公會交付。

第一章目前只解鎖並顯示預告。離開前請手動保存；本包沿用新版專用存檔槽位 crystal_g06_slot_01.json，舊版 crystal_slot_01.json 由既有安全遷移流程讀取，原檔保留。
