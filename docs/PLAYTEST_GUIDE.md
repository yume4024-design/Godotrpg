# 《失落星核》序章試玩 0.6.1

Windows x64，解壓縮後執行 ProjectCrystal.exe；請讓 ProjectCrystal.pck 保持在同一資料夾。
需要 OpenGL 3.3、繁體中文字型（目前使用 Windows 微軟正黑體）。本版本是本機測試版，未作數位簽章。

## 操作

| 功能 | 鍵盤／滑鼠 | Xbox |
| --- | --- | --- |
| 移動 | WASD／方向鍵 | 左搖桿／十字鍵 |
| 互動／對話 | E／空白／Enter | A |
| 手冊 | M | Menu |
| 確認選單／戰鬥 | 滑鼠／Enter | A |
| 選擇／切換焦點 | 方向鍵／Tab、Shift+Tab | 十字鍵／RB、LB |
| 返回／取消目標 | Esc | B |
| 保存／讀取 | F5／F9，或手冊→旅程 | 手冊→旅程 |
| 音量／靜音 | 手冊→音量 | 手冊→音量 |

按 A／E 第一次顯示完整對話，再按一次前往下一句。戰鬥先選指令，再選目標；B／Esc 取消目標不消耗回合。

## 序章路線

1. 灰石村開場，找公會長接委託，再找莉雅入隊。
2. 開手冊→裝備，給雷恩裝青銅劍、莉雅裝柳木法杖；防具可自行分配。
3. 前往低語森林，在補給箱取得恢復藥，再前進遭遇史萊姆。營地可以休息。
4. 由森林東侧前往礦坑，深入取得兩瓶藥，調查星晶，擊敗腐化守衛。
5. 經森林返回村莊，找公會長交付；完成章末對話與預告後保存。

只有雷恩／莉雅兩人；第一章目前只有解鎖與預告。戰鬥演練不發主線獎勵。

本版更新灰石村藍頂公會、水晶廣場、棚布住宅與山谷河岸。前往森林仍需在東側旗幟入口按 A／E；橋、河道、外圍住宅與風車為遠景，沒有新增可進入房屋或交易功能。水車與水面目前為靜態造景。

## 保存與聲音

離開遊戲前請手動保存。忙碌時的保存請求會延後至探索安全點；讀取不會中斷戰鬥。
一般直接啟動的存檔在 `%APPDATA%/Godot/app_userdata/失落星核 — Project Crystal/`，主檔 `crystal_slot_01.json`，上一份有效備份為 `.bak`。
開發工具啟動時使用專案 `artifacts/godot-user` 下的隔離位置，與直接雙擊版本不同。不要在多個遊戲視窗同時寫同一存檔。
音量設定獨立保存在 `audio_settings.cfg`，不影響冒險進度。

## 本版驗收邊界

這是序章整合試玩版；完整 20～30 分鐘節奏、玩家實機手把全程通關與長時間效能仍需試玩驗收。自動化加速通關不代表時長合格。
請記錄：通關所需時間、卡關位置、讀檔後是否一致、手把導航或音量是否異常。
模型、旋律、音效為本專案原創；引擎授權見隨附 GODOT_LICENSES.txt，素材清單見 ASSET_CREDITS.md。
