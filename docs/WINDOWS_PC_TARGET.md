# Windows PC 開發與效能基準

## 2026-11-08 使用者決策（優先於歷史平台規劃）

Android 與 iOS 開發永久中止，不再列為待辦、暫停項目或序章發布門檻。停止行動平台 SDK／JDK／匯出模板、APK／IPA、真機、觸控專屬功能與手機效能優化工作。既有共用輸入程式與歷史測試證據保留；保留不表示繼續手機開發，不為移除舊功能破壞 PC 遊戲。

唯一開發與驗收平台為 Windows PC；鍵鼠與 Xbox／XInput 是有效操作方式，跑步維持 LB。優化以使用者目前電腦為主，不再用手機規格限制場景／模型品質，也不將其他低階 PC 當作本輪發布門檻。保留既有畫質設定；畫質調整必須兼顧參考圖還原度，不能靠隱藏必要物件或取消碰撞獲取成績。

## 實測硬體（2026-11-08）

- CPU：AMD Ryzen 5 5600，6 核心／12 執行緒。
- RAM：系統回報 34,239,037,440 bytes（約 31.89 GiB，32 GB 級）。
- GPU：NVIDIA GeForce RTX 3080，12,288 MiB VRAM；驅動 617.42。
- 目前顯示模式：1920×1080、60 Hz；另有 Virtual Desktop Monitor，測試須記錄實際使用的顯示器／視窗與渲染尺寸。
- 引擎保持 Godot 4.7.2；現有 Compatibility 渲染器不因新平台決策自行切換。

## 角色與場景細緻度（同日追加授權）

使用者允許提高角色與場景精緻度。沿用已確認的人物設計與場景參考圖，優先改善可見品質，而非一律增加面數。

- 角色：衣物邊緣厚度、領口與袖口接縫、手指與持物接觸、五官／頭髮表面、皮革與布料質感；保持骨架、動作及身分資料完整。
- 場景：建築木框／屋簷／石基、岩層與地表材質、水體流動與岸邊接合、近景道具細節；保持既有布局、路線、NPC 錨點與碰撞。
- 不再把舊手機或早期5000面預算當作新版角色的硬性上限；依視覺必要性及本機測試調整模型／貼圖成本。不能以高面數掩蓋破面、貼圖接縫或比例問題。
- 每一批改動提供同鏡頭／光照／解析度前後畫面，檢查探索、施法／持劍及動畫切換，再量測1080p成本。未進行的美術升級保留待辦，不能以提高反鋸齒設定冒充完成重建。

## Windows 驗收目標

- 以 1920×1080、高畫質、60 FPS 為主要目標；16.67ms 是幀預算，目標不是已達成結果。
- 記錄平均、P95／P99／最大幀時間、Draw Calls、引擎配置記憶體與程序 working set／private bytes；分開標示啟動、探索、戰鬥、切圖與讀檔尖峰。
- 對照測試使用相同硬體、分辨率、渲染器及流程；歷史 1280×720 成績不能宣稱是 1080p 驗收。
- 使用 Windows 原生 Release 候選，至少 30 分鐘圖形長測，以及序章、存檔重啟與鍵鼠／Xbox 回歸；短診斷、無頭測試及合成輸入各自如實標示。
- 人工最終驗收仍依先前指示暫停；永久取消手機不代表 Windows 尚缺的驗收已通過。
- 保留正式 v0.6.1、舊存檔與原始資產；角色 ID、數值、旗標、任務收據與存檔 Schema 不因效能優化改變。
