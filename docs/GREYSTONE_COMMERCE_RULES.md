# G06.4 交易規則（2026-10-15）

- 道具商店目前只販售既有恢復藥 potion：5 金幣/瓶，一次 1～99 瓶；背包與累計購入各上限 9999。沒有賣出、贈品、折扣或裝備買賣。
- 旅館每隊每晚 10 金幣，PartyManager.rest 恢復全部隊員 HP/MP（含倒下成員）。全員已滿不扣款；缺錢、距離不符、忙碌或非法數量時所有狀態不變。住宿累計上限 10000。
- 每次確認只提交一次，成功立即關閉交易視窗並顯示結果對話；重複回呼因交易已關閉被拒絕。取消不更動任何資料。商店開啟時鎖移動、選單/切圖/讀檔，保存延至交易結束。
- InventoryManager 唯一持有支出與購入累計；UI 僅發確認/取消請求。住宿由現有 PartyManager 執行，通知前完成扣款/帳本及全隊恢復。
- schema 3 / CH00-G06.4：inventory.commerce = {potion_bought: 非負整數, inn_stays: 非負整數}。金幣精確等於獎勵收據總額 - 購入數*5 - 住宿數*10；藥品存量不得超過既有領取量+購入量（允許戰鬥/選單消耗）。EXP、裝備、任務及星印仍使用原嚴格契約。
- v1/v2 不允許 commerce 欄位；先驗原契約與原位置，v1 按既有位置遷移，然後加入零交易帳本並驗證 schema 3。載入不改寫來源檔。正式 v0.6.1 只接受 v1。
- 經濟沒有新金幣來源，交易帳本與收據為一致性驗證，不聲稱防作弊。既有礦坑/森林/村出口維持 G06.3；鐵匠僅對話。Android 真機驗收不在本階段。
